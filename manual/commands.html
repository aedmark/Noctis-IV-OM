CLR : Clear Output Buffer

📡 GOESnet Terminal Sync Action: clear_output 
SYNOPSIS: CLR
What It Does

Clears the entire text display buffer of Bulkhead Screen 1, resetting the scroll offset and returning the pager cursor to the top.

How It Works

Dispatches GoesCommand::clear. The terminal state resets its 147-cell visible window memory to spaces and returns GoesResultAction::clear_output.

Why It Works

Prevents long search results from cluttering subsequent parameter readouts, maintaining clean cockpit visibility.

HELP : Command Documentation

📡 GOESnet Terminal Sync 21-Column Pager 
SYNOPSIS: HELP [topic]
What It Does

Displays an alphabetical index of all available GOESnet commands or detailed multi-line instructions for a specified topic.

How It Works

Parses optional topic argument. Formats output lines into exact 21-character rows wrapped with decorative &&&&&&&&&&&&&&&&&&&&& dividers.

Why It Works

Self-documenting terminal ensures explorers can operate ship systems without referring to external manuals during flight.

PAR : Celestial Parameters

📡 GOESnet Terminal Sync Starmap Query 
SYNOPSIS: PAR <object>[:range]
What It Does

Retrieves astrophysical parameters for a named star or planet, including coordinates, mass, temperature, radius, and orbit index.

How It Works
  1. Resolves <object> against STARMAP.BIN index and active flight logs.
  2. Derives star coordinates ($x, y, z$) within specified light-year search range (default 100).
  3. Calls star_properties() or system_properties() to compute procedural astrophysics.
Why It Works

Ensures that celestial telemetry displayed on screen matches the procedural simulation physics exactly.

WHERE : Location & Parent Body

📡 GOESnet Terminal Sync Hierarchy Search 
SYNOPSIS: WHERE <object>
What It Does

Locates the parent star and planetary system holding a named moon or planetary body.

How It Works

Inspects the target's StarmapRecord kind. If a planet, subtracts its orbital ordinal offset to resolve the host star ID, returning the primary star's name and galactic coordinates.

Why It Works

Prevents explorers from getting stranded when given an isolated planetary designation without stellar context.

ST : Set Navigation Target

📡 GOESnet Terminal Sync Action: set_remote_target / set_local_target 
SYNOPSIS: ST <object>[:range]
What It Does

Locks the Stardrifter's autopilot and navigation HUD onto the specified celestial destination across interstellar or interplanetary space.

How It Works

Resolves coordinates and injects guidance vector into EngineState. Sets GoesResultAction::set_remote_target for stars or GoesResultAction::set_local_target with planet index.

Why It Works

Direct bridge between terminal text commands and active 3D flight HUD steering.

INBOX : Import Starmap Packet

📡 GOESnet Terminal Sync Action: catalog_changed 
SYNOPSIS: INBOX [CHECK|CK|<file>]
What It Does

Inspects, validates, and merges external community starmap packets (.nsm or .json) into your local catalog.

How It Works
  1. If CHECK is passed, performs a non-destructive dry run reporting collision counts.
  2. Verifies packet CRC32 and validates bounding limits.
  3. Applies conflict resolution: skips canonical bodies and merges non-conflicting labels atomically.
Why It Works

Enables asynchronous community cartography without central servers.
